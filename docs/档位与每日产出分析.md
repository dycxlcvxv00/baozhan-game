卡面三来源口径 → 档位分析该用哪个数（2026-11-11 夜）

【卡面现在并排三个来源】
  · 异界产出（青）= dsrc='dun' 段的残差之和  ← 纯净，做档位分析用这个
  · 市集收入（靛）= dsrc='mkt' 段的残差之和  ← 已扣掉转入，不含转移
  · 转移收入（粉）= 别的号转进来的实收额（扣 5% 手续费）← 站内搬砖，不算收入

【为什么现在终于能分开了】
  闭合反推的残差公式 v =（期末 − 期初）+ 流出 − 转入，
  **转入已经被扣掉** → 市集桶里天然不含转移，两者天然不重叠。
  恒等式（已用断言锁住）：余额总增 = 异界产出 + 市集收入 + 转移实收。

【对档位分析的影响】
  1. 「档位加成 → 每日产出」的分子**只能用异界产出**。
     旧的「累计获取(含市集)」是混合口径（含集市买入、任务奖励，实测约占 62% 非异界来源），
     用它会把「市集买卖」误算成「档位加成带来的产出」——这正是之前曲线解释力差的原因之一。
  2. 转移收入永远不进分子：它是同一个号之间搬晶石，全站合计会互相抵消，
     只有单号视角下才看得到（净调拨量 = 转移收入 − 累计转出）。
  3. 市集收入要**单列**看：它反映的是「号有多活跃/多能卖」，不是「档位加成」。
     后面可以做「档位 → 市集周转率」的分析，但那是另一个问题。
