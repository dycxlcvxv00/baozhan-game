# 爆战丨无限弹幕

横向防守 + 符文构筑的 HTML5 弹幕塔防游戏。

- 试玩地址：https://dycxlcvxv00.github.io/baozhan-game/
- 当前版本：v1.0（Phaser 3 引擎重构版）

## 技术架构

- 引擎：Phaser 3（3.90，`lib/phaser.min.js` 仓库本地引用，无 CDN / 无构建工具，纯静态部署）
- 分层：`js/sim.js` 纯逻辑（数值 / 判定 / 波次 / 符文充能，无引擎依赖，node 可直接仿真测试）；`js/main.js` Phaser 表现层（Scene 只负责输入、渲染、动画与事件桥接）
- 适配：1280×720 固定舞台，Scale Manager FIT 等比缩放居中；竖屏显示横屏提示
- 存档：localStorage 键 `baozhan_save_v1`（旧版存档已作废）

## 核心玩法规则

- 战场：左侧玩家区（英雄 + 16 槽六边形符文锯阵），中间围墙，右侧刷怪区（约 3.5 : 6.5）
- 英雄：固定站位，每秒自动普攻，攻击力 100，锁定距离围墙最近的怪物
- 围墙：生命 1000，归零判负；坚壁符文提供护盾（上限 150）
- 怪物：普通怪（生命 100 / 攻击 20 / 攻速 1.5s）、高血怪（300 / 35 / 1.8s）；最右 3 个网格列出生，出生 1 秒无敌不可选中
- 波次：每关 3 波（6 普通 / 8 普通 + 1 高血 / 10 普通 + 2 高血），全部波次刷完且场上无怪即胜利
- 符文：16 个六边形槽位（上 8 下 8），可装配 0～5 个不同符文，每种最多一次；每秒自动充能 +1，英雄普攻命中随机 1 个已装配符文 +1，满能自动释放
- 五个符文：爆裂火球（范围 120）、寒冰锥刺（穿透 80 + 减速 30%）、连锁闪电（90 连锁 5 次衰减 15%）、腐蚀毒箭（直击 60 / 溅射 24 / 中毒 12×5s）、坚壁符文（护盾 150，围墙受击 +2 能量）

## 开发规范（AI 协作）

- 只用 3.60+ 现行 API，禁止已废弃写法（旧粒子 API 等）
- 资源统一在 Scene 的 preload 阶段加载
- 子弹 / 特效 / 伤害飘字等高频对象一律对象池复用，禁止频繁 new / destroy
- 滤镜特效需有降级方案（Canvas 回退模式可玩）
- 手机无 hover，提示用「点一下查看、再点确认」
- 引用文件名带版本号，防止缓存到旧版
